# tktk

Prototype feedback interface for a poetry/writing-workshop mini-LMS. Built to gather feedback from a workshop instructor stakeholder; not production software.

## Demo

Live demo: https://dgabriel.github.io/tktk/

Deployed automatically from `main` via GitHub Pages (see `.github/workflows/deploy-prototype.yml`).

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
